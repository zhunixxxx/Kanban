# 四象限工作看板

基于艾森豪威尔矩阵的每日任务看板，界面遵循 [Arco Design](https://arco.design) 设计规范。

## 四象限

| | 紧急 | 不紧急 |
|---|------|--------|
| **重要** | 重要且紧急 · 立即处理 | 重要不紧急 · 计划安排 |
| **不重要** | 紧急不重要 · 尽量委派 | 不重要不紧急 · 减少删除 |

## 功能

- 2×2 四象限矩阵布局
- **今日 TODO**：仅显示今天在开始～截止范围内的未完成项，按象限优先级自动排序
- **分组**：分组名最多 20 字，弹窗管理，从 20 种主题预设色中选择；看板任务背景显示分组色
- **备注**：任务详情中可添加备注（最多 500 字）
- **日期**：每项任务有开始日期与截止日期，新建时默认为创建当天；过期未完成项以红色标注
- 拖拽在象限间移动任务
- 快速添加：顶部输入框、今日 TODO / 象限列表底部入口
- 详细添加：弹窗填写标题、分组、重要程度、备注
- 点击任务打开详情弹窗（编辑）
- 勾选标记完成
- 显示 / 隐藏已完成任务
- 清除已完成任务
- **本周概览**：按天梳理本周（周一至周日）已完成任务，含分组、象限与完成时间
- 状态栏：完成度圆环 + 进度条，可切换显示已完成
- **自动保存**：在设置中关联本地 JSON 文件后，变更将自动写入（Chrome / Edge 等，约 1 秒防抖）
- 导出 / 导入 JSON 备份（设置内操作，跨设备同步）
- 自动迁移旧版 Kanban 数据
- **主题风格**：浅色、暗色、少女粉、香芋紫、婴儿蓝、鹅绒黄、森林绿（设置内切换，偏好保存在本机）
- 右上角图标：本周概览、分组管理、清除已完成、设置

## 使用

直接用浏览器打开 `index.html`，或启动本地服务器：

顶部日期旁会显示当地天气（基于 [Open-Meteo](https://open-meteo.com/)，首次需允许浏览器定位；未能获取位置时使用上海作为默认位置，缓存 30 分钟）。

```bash
python3 -m http.server 8080
```

然后访问 http://localhost:8080

## 备份与同步

点击右上角 **设置**（扳手图标）→ **数据**：

- **自动保存**：勾选并选择 JSON 文件，之后每次修改会自动写入该文件
- **手动备份**：**导出** 或 **导入** JSON 文件

- 若当前已有任务，导入时会询问：**覆盖**（替换全部）或 **合并**（相同 ID 以导入文件为准）
- 将 JSON 文件拷贝到其他设备后导入，即可同步任务数据
